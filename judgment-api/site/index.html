02 / METHOD

一条可以读懂的本地流程

TF-IDF + LinearSVC + 规则
  1. 01

    整理课程语料

    从 3,520 份文书提取案由、法条、方向和主文，以“本院认为”之前的案情作为模型输入。

    本地读取 · 本地提取
  2. 02

    检索相似案件

    用中文字符 TF-IDF 表示文本，寻找相似案情。法条只从本地相关案例的实际引用中选择。

    字符词组 · 相似度检索
  3. 03

    预测判决方向

    LinearSVC 学习支持、部分支持、驳回三个方向；明确的交付、还款及证据事实由规则处理。

    轻量分类 · 事实规则
  4. 04

    组装新案主文

    依据本次输入的请求与金额生成条款，不直接复制邻案的姓名、案号或金额；无法确定时保留限制。

    四字段输出 · 明示不足
A

计算边界

索引与分类在 Windows 电脑执行。Cloudflare 在正式测试中仅转发请求；本项目未调用外部大模型，也未微调生成模型。

B

数据边界

课程源文书不随源码发布。原始及结构化全文、检索索引、密钥和运行日志均保留在本地；运行者需自行准备获授权的课程数据。

03 / LIMITATIONS

保留失败，说明边界

这次实践验证了服务交付链路，也暴露了司法文本理解的难点。

01

相似案，不等于相同结论

文本相似可能掩盖证据、主体和履行条件的差异。正式测试中，方向得分为 0.50，不能据此宣称可靠自动判案。

02

复杂主文仍可能无法生成

多项诉求、损害分摊、利息公式及事实争议容易超出规则能力。缺少明确依据时，不猜测支持比例或金额，结果会说明无法确定。

03

历史引用不代表现行适用

法条来自本地历史案例，未从外部补充或核验现行效力。法名匹配与具体条款匹配，都不能代替法律适用判断。

04 / RUN LOCALLY

在自己的电脑上运行

完整 README ↗

先启动程序，再打开运行页

需要 Windows，建议使用 Python 3.12，并自行准备课程 judgments.jsonl。源码不包含这份数据。

打开本机运行页 ↗

本机地址：http://127.0.0.1:8001/
如果无法打开，请先完成右侧步骤。网站不会自动启动你的电脑程序。

关闭网页不会停止后台服务。电脑关机、休眠或断网会中断本机服务与连接。
01下载源码与安装依赖+

下载仓库并进入 judgment-api 目录，在该目录运行：

python -m pip install --target .deps -r requirements-lock.txt

其他环境可参见 README 的最小依赖清单。

02配置自己的本地数据与 Key+

推荐运行配置助手，在自己的电脑填写课程数据路径并生成作业专用 Key：

python configure.py

配置保存在本机 .env。下方仅示意配置形状，均为占位符；手动配置时，Key 需换成至少 20 个字符的随机字符串。

JUDGMENTS_PATH=C:/your-course-data/judgments.jsonl
JUDGE_API_KEY=YOUR_COURSE_KEY

不要将真实 Key 或课程数据提交到公开仓库。Cloudflare 程序的准备方式见 README。

03启动本机服务+
python manage.py start

首次启动会建立本地索引与分类器。正式测试使用的公网入口是临时连接；重新启动后，请以程序显示的地址为准。

04打开可见的运行页面+
python dashboard.py --open

也可使用项目中的 打开运行页面.cmd。运行页只监听本机地址，可查看服务状态和进行真实的本机测试。

05 / INTERFACE

简洁的接口约定

示例文案完全虚构 · 不是实时判决
GET

/health

无需 Key，正常时返回 {"ok": true}。

POST

/judge

通过 Bearer Key 鉴权，提交 case_text，返回案由、法条、方向、主文。

缺少或错误的 Key 返回 401。本页只说明接口，不发送判案请求，也不收集 Key。
格式演示
POST http://127.0.0.1:8000/judge
Authorization: Bearer YOUR_COURSE_KEY
Content-Type: application/json

{
  "case_text": "虚构示例：原告请求偿还借款本金10000元。借条及转账记录证明本金已交付，被告已返还2000元，双方确认尚欠8000元。"
}
{
  "cause": "民间借贷纠纷",
  "laws": ["《中华人民共和国合同法》第二百零六条"],
  "direction": "部分支持",
  "verdict": "一、被告向原告支付借款本金人民币8,000元。二、驳回原告超过上述金额部分的诉讼请求。"
}

内容为人工编写的虚构格式示例，未在此页面执行。法条仅示范本地历史案例的引用格式。
